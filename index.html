月页 · MoonTab 隐私政策

本政策适用于 Microsoft Edge 加载项中的月页扩展（原名檐间 · Eavelle）。更新于 2026-11-06，自相应版本公开发布时适用。Read in English

本机工作台

扩展使用浏览器存储保存你添加的网站、分组、布局、外观、偏好和小组件数据。便签、待办、日期事件、习惯记录、上传图片和恢复点保存在本机。你主动导出的完整备份可能包含这些资料。

浏览器收藏管理

你在收藏管理器中主动授权后，扩展使用可选 bookmarks 权限读取当前浏览器的收藏树，用于本机浏览、搜索和整理。新建、编辑、移动与删除会直接修改浏览器收藏，浏览器自身的账号同步可能传播这些修改。扩展不会将原始收藏树另存到工作台或上传到坚果云。只有你主动添加到新标签页的网站名称和网址会成为工作台条目，并按启用的同步方式处理。取消授权后管理器清空已读取内容，已添加到工作台的网站可单独删除。

可选同步

你可选择一种同步方式。Edge 账号同步通过 Microsoft Edge 的同步服务保存网址与名称、分组、布局、主题及轻量设置，例如手动填写的天气城市、时区和在线壁纸来源。

坚果云同步通过 HTTPS 将同类轻量配置写入你指定的坚果云目录。坚果云账号和第三方应用密码保存在当前浏览器的扩展本机存储中，用于直接向坚果云认证。凭据与同步配置分开保存。自动同步默认关闭。

其他联网功能

提交搜索时，搜索词会发送到你选择的搜索引擎。点击网站会访问对应站点。经浏览器授权的图标补全会访问目标网站或图标来源，在线壁纸请求会访问选定的必应、Wallhaven 或 Deepin 壁纸来源，天气按你填写的城市请求 Open-Meteo。各服务会收到完成请求所需的信息和常规连接信息，并适用各自的隐私政策。

扩展的历史入口打开 Edge 自带页面。扩展程序随安装包分发。工作台数据用于提供扩展功能，项目没有广告跟踪、数据出售或开发者运营的同步后台。

导出、删除和联系

在「设置 → 数据与同步 → 本机备份与恢复」可导出或导入工作台。可在收藏管理器取消收藏夹授权，也可在 Edge 扩展设置撤回可选权限或卸载扩展。停用同步会停止后续同步，已有远程副本可在 Edge 同步设置或坚果云中管理。清除坚果云连接会移除本机凭据，也可在坚果云撤销应用密码。

如有隐私问题，请通过 月页支持页 联系维护者。该页面公开，请勿在反馈中附上密码、私人网址或完整工作台备份。

MoonTab Privacy Policy for Microsoft Edge

This policy applies to MoonTab, formerly Eavelle, distributed through Microsoft Edge Add-ons. Updated November 6, 2026, for the corresponding published version.

Local workspace

The extension uses browser storage for the sites, groups, layouts, themes, preferences and widget data you add. Notes, tasks, date events, habit records, uploaded images and recovery points stay on the device. A full backup you choose to export may contain this data.

Browser bookmark management

When you grant optional bookmarks permission in the manager, the extension reads the current browser bookmark tree for local browsing, searching and organization. Creating, editing, moving or deleting entries changes the browser bookmarks directly, and the browser’s own account sync may propagate those changes. The extension does not separately save the original tree in its workspace or upload it to Nutstore. Only the website names and addresses you explicitly add to the new tab become workspace entries and follow your enabled sync method. Revoking permission clears the manager’s loaded content; imported workspace sites can be deleted separately.

Optional sync

You can enable one sync method at a time. Edge account sync uses Microsoft Edge sync storage for saved site names and addresses, groups, layouts, themes and lightweight preferences such as manually selected weather cities, time zones and online wallpaper references.

Nutstore sync sends the same types of workspace settings over HTTPS to a folder you specify. Your Nutstore account and app password are stored in local extension storage and sent directly to Nutstore for authentication. Credentials are kept separate from the workspace snapshot. Automatic sync is off by default.

Network features

Submitting a search sends your query to the selected search engine. Opening a shortcut visits the destination site. With browser permission, icon lookup can contact the site or an icon source, online wallpapers can contact Bing, Wallhaven or Deepin, and weather can send a manually selected city to Open-Meteo. These providers receive the information needed for their requests and normal connection information under their own privacy policies.

The history shortcut opens Edge's built-in history page. Extension code ships in the package. The project does not sell user data, track users for advertising or run its own sync server.

Control and contact

Use Settings → Data & Sync to export or import your workspace. You can revoke bookmark access in the manager, or revoke optional permissions and uninstall the extension in Edge settings. Turning sync off stops future sync. Manage existing cloud copies in Edge sync settings or Nutstore. Clearing the Nutstore connection removes local credentials. You can also revoke its app password in Nutstore.

For privacy questions, use the MoonTab support page. Support issues are public. Keep credentials, private URLs and full backups out of issue posts.
